
Command line:  list tmux session:
tmux ls

Command line:  attach to most recently created session:
tmux a

Command line:  attach to session by its number:
tmux a -t #

Command line:  specify configuration file, if it's not initialized automatically:
tmux source-file ~/.tmux.conf


---------------------------------------------------

Command line:  start new session, attach it if it exists, and name it "session_name"
tmux new-session -A -s session_name

Command line:  start new session, run command, and keep session open:
tmux new-session "ls: bash"

Command line:  list all sessions:
tmux list-sessions

Command line:  kill all sessions:
tmux kill-server

Kill current session:
Prefix + :kill-session


---------------------------------------------------

Prefix is Ctrl+b by default; remapped to Ctrl+A

create new session:
Prefix + :new

create new window in current session:
Prefix + c

detach from session:
Prefix + d

open panel to move among sessions and windows:
Prefix + w 
Prefix + s

move to next/prior session:
Prefix + (
Prefix + )

move to next/prior window:
Prefix + n
Prefix + p

move to next/prior pane:
Prefix + {
Prefix + }


move between panes directionally:
Prefix + arrow-key

move to next pane:
Prefix + o

zoom/unzoom current pane:
Prefix + z

cycle through pane layouts:
Prefix + Space

resize panes:
Prefix + Ctrl + (repeated) arrow keys


Vertical split:
Prefix + %

Horizontal split:
Prefix + "

close current pane:
Prefix + x

View all keybindings (press 'q' to exit):
Prefix + ?

View pane numerical identifiers:
Prefix + q


---------------------------------------------------

enter copy-mode/buffer:
Prefix + [

start copy selection:
Space

end copy selection:
Enter

paste selection:
Prefix + ]



exit/cancel copy-mode/buffer:
Ctrl + c
q


---------------------------------------------------

Open existing session read-only in current pane (where `TMUX=` unsets the tmux environment variable to allow nested sessions and `0` is the session name, which defaults to numbers if a name hasn't been explicitly set):
TMUX= tmux attach-session -t 0 -r
